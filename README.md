# Budget vs Actual Expense Analysis – Power BI

## Project Overview

This project analyzes actual expenses against the planned budget using Power BI. The dashboard helps identify spending differences, calculate variance and variance percentage, and highlight departments or categories with significant budget gaps.

## Objective

* Compare budgeted expenses with actual expenses
* Calculate absolute variance
* Calculate variance percentage
* Identify material budget gaps
* Analyze expense performance across departments, categories, regions, and time
* Create an interactive Power BI dashboard

## Tools Used

* Power BI
* DAX

## Dataset

The dataset contains financial transaction information including:

* Date
* Department
* Category
* Region
* Budget Amount
* Actual Amount
* Payment Method
* Transaction ID

## Dashboard Components

### KPI Cards

* Total Budget
* Total Actual
* Variance
* Variance %
* Material Gap

### Charts

1. Budget vs Actual Expenses by Month
2. Budget vs Actual by Department
3. Variance % by Expense Category
4. Expense Variance by Region

### Material Gap Analysis

A detailed table shows:

* Department
* Category
* Budget Amount
* Actual Amount
* Variance
* Variance %
* Material Gap Status

## Dashboard Filters

The dashboard includes interactive slicers for:

* Date/Year
* Department
* Category
* Region

These filters allow users to analyze budget performance for specific periods and business areas.

## Key Insights

1. Actual expenses can be compared directly with planned budget to identify overall spending performance.
2. Positive variance indicates that actual expenses are higher than the budget.
3. Negative variance indicates that actual expenses are lower than the budget.
4. Variance percentage helps compare budget gaps proportionally rather than only by absolute amount.
5. Departments, categories, or regions with a Material Gap require closer attention because their actual spending differs significantly from the planned budget.

## Conclusion

The Power BI dashboard provides an interactive view of budget performance and expense variance. It helps users quickly identify spending gaps and analyze where actual expenses differ significantly from planned budgets.
